Het Maximale Bereik (Vanaf 2014):
Als je écht een grote dataset wilt bouwen, start je in 2014. Dit is het begin van het huidige Turbo-Hybrid tijdperk (de V6-motoren). Data van vóór 2014 gebruikt fundamenteel andere motoren (V8) en racestrategieën (zoals tanken tijdens de race), wat vergelijkingen met het huidige racen voor een AI-model heel ruisgevoelig maakt.
